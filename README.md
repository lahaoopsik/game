# Солнечная долина — Unity

Основной проект: [unity](unity/README.md). Unity 6.3 LTS, 6000.3.27f1 / C#.
Главный визуальный ориентир — Core Keeper и Stardew Valley, собственные ассеты.

Локальный запуск: <папка разработки>/Играть.cmd.
Редактор: <папка разработки>/Редактор.cmd.
Другой seed: <папка разработки>/Мир Unity по seed.cmd.
На другом ПК откройте папку unity в подходящем Unity Editor; затем Sunny Valley →
Prepare scene / Verify migration. Windows-сборка создаётся ProjectSetup.Build.

Целевой рельеф — естественные земляные террасы с травяной кромкой и пологими
подъёмами. Камень — отдельные залежи. Старые стеновые блоки прототипа ещё требуют
замены. Вода находится ниже пола и проходима только по мосту. Первый гибридный генератор создаёт один стартовый биом: рощи, поляны,
редкие пруды, главное озеро, ручей, защищённые старт и деревню, связанные маршруты.
[План и параметры генерации](unity/GENERATION.md).

Перенесены базовые команды рубки, древесина, инвентарь 9+6 с переносом стопок,
чертёж верстака с доставкой и работой, размещение/повороты декора, главная палатка
с интерьером, карта, меню, цикл суток, первые источники света и отражения воды.
Это первый рабочий этап переноса. Художественное оформление ещё в работе.
Герой и крупные объекты пока с прежними временными изображениями; новые стартовые
блоки сделаны на маленькой пиксельной сетке. Отклонённая полная перерисовка не используется.

Проверены 100 seed, команды и сохранение; Windows-сборка и реальный запуск.
[Отчёт генерации](unity/Reports/generation.csv).
Не реализованы кооператив, приручение, рабочий ИИ, здоровье/энергия связей,
добыча руды и рост урожая. Тряска/падение деревьев и полноценные тени требуют переноса.

Godot удалён из рабочей папки и с компьютера по просьбе пользователя.
История предыдущей версии остаётся в Git. Локальная проверенная резервная копия
удалённых файлов — <папка разработки>/backups\godot-before-removal-2026-10-29.zip.

Утверждённый художественный эталон: unity/ArtDirection/approved-village-topdown-v2.png.
Запуск безрамочный полноэкранный; F11 переключает оконный режим.
